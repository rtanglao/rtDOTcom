[Discovered](http://rolandtanglao.com/2020/07/29/p1-blogthis-checkvist-list-links-to-blog/): Nov 4, 2026 14:29 (UTC) [Tools for support folks that should come out of the box but never do :-) part 8888 Espanso and Keyboard Shortcuts (AutoHotKey on Windows, built-in app on macOS) for github issues, bugzilla links, etc etc :-) ](https://github.com/thunderbird/espanso-config)

Heavily customized for my needs but easily customized to yours :-) :

* `:hamburger` for Thunderbird app menu SUMO KB markup
* `:warmgreet` for a randomly picked greeting
* `:warmclose` for a randomly picked closing
* `Command+Control+z` for a Zendesk ticket link For this and the following links, if you also hold down shift i.e. `Shift+Command+Control+z` it will do HTML links as well as markdown links
* `Command+Control+y` for a Notion link
* `Command+Control+g` for a Github issue link
* `Command+Control+u` for a Bugzilla bug link
* `Command+Control+l` for a link to a page where our cursor is focused like this in Markdown `[title of current tab )[url of tab]`
